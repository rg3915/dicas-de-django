## Pontos principais

* Front e back separados custam o dobro: dois conhecimentos, mais tempo, mais dinheiro. Um monolito Django com HTML, CSS e HTMX ou Alpine.js resolve muita aplicação.
* O admin do Django te dá CRUD pronto para cada model registrado. Antes de criar telas de cadastro para uso interno, veja se o admin já resolve.
* Com o ORM do Django, o mesmo código serve para PostgreSQL, MySQL, MariaDB ou Oracle.
